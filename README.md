# 학급 행동 기록판

교사가 **학생 칸 → 행동 버튼** 두 번의 클릭만으로 수업 중 학생 행동을 기록하는 웹 앱입니다.
설치가 필요 없는 단일 HTML 파일이며, 인터넷이 끊겨도 동작합니다.

## 주요 기능

- **2회 클릭 기록** — 학생 칸을 누르고 상단 행동 버튼을 누르면 시각과 함께 저장
- **자유 자리 배치** — 배치 모드에서 학생 칸을 끌어 모둠·통로 그대로 배치 (칸 크기 3단계)
- **이상행동 색 경고** — 그날 '주의' 누적 1~2회 노랑, 3~4회 주황, 5회 이상 빨강
- **화장실·보건실 외출 추적** — 나가면 보라색, 칸을 다시 누르면 복귀 처리, 10분 초과 시 화면 경고
- **특이사항 메모** — '기타' 버튼이나 하단 버튼으로 입력창을 열어 기록
- **시간표** — 교시별 시간과 요일별 과목을 입력하면 기록에 교시·과목이 자동으로 붙습니다
- **기록 정리** — 과목별·교시별·학생별로 기간(오늘/최근 7일/전체)을 골라 집계
- **엑셀(xls) 내려받기** — 행동기록·학생별집계·과목별집계·교시별집계 4개 시트
- **백업 파일** — 명단·자리·기록 전체를 JSON으로 내려받고 되살리기 (기기 이동에도 사용)
- **의견 보내기** — 버전·화면 정보가 자동으로 담긴 의견 양식 (학생 정보는 담기지 않음)
- **계정** — 아이디·비밀번호만으로 만드는 브라우저 안의 잠금장치, 계정별로 학급 데이터 분리

## 사용법

1. `index.html`을 브라우저로 열거나, 배포된 주소로 접속합니다.
2. 처음이면 **회원가입**에서 아이디·비밀번호만 정해 계정을 만듭니다. (이름·이메일은 받지 않습니다)
3. **설정 → 학생 명단**에 `번호 이름`을 한 줄씩 입력해 저장합니다.
4. **설정 → 자리 배치 → 배치 모드**에서 칸을 끌어 교실 모양대로 배치합니다.
5. **설정 → 시간표**에서 교시별 시간과 요일별 과목을 입력합니다. (기록에 교시·과목이 자동으로 붙습니다)
6. 수업 중에는 학생 칸 → 행동 버튼 순으로 누릅니다. 헤더에 지금 교시·과목이 표시됩니다.
7. 화면 오른쪽 위 **📊 정리**에서 과목별·교시별·학생별로 모아 봅니다.
8. **설정 → 데이터 내려받기**에서 xls(보관용)와 백업 파일(복원용)을 받아 둡니다.

## 데이터와 개인정보

- 학생 이름·기록·자리 배치·계정은 **접속한 브라우저의 localStorage에만** 저장되며 서버로 전송되지 않습니다.
- 비밀번호는 원문 대신 salt를 붙인 PBKDF2-SHA256(15만 회) 해시로만 저장됩니다. 분실 시 복구할 수 없습니다.
- 브라우저 저장소를 비우면(인터넷 사용 기록 삭제, 시크릿 창 종료 등) 기록도 함께 사라집니다.
  **학기 중 주기적으로 백업 파일과 xls를 내려받아 보관하세요.** 백업 파일은 다시 불러와 되살릴 수 있고,
  xls는 보관·분석용입니다.
- 저장 공간이 부족할 때 브라우저가 기록을 지우지 않도록 로그인 시 저장 유지를 요청합니다(브라우저가 지원할 때만).
- 로그인은 이 기기 안에서의 잠금 장치일 뿐, 서버 인증이 아닙니다. 공용 PC에서는 사용 후 로그아웃하세요.

## 배포 (GitHub Pages)

```bash
git add -A
git commit -m "설명"
git push
```

`main` 브랜치에 올리면 GitHub Pages가 자동으로 갱신합니다.
버전을 올릴 때는 `index.html`의 `APP_VERSION`과 아래 이력, git 태그를 함께 맞춥니다.

```bash
git tag -a v1.0.1 -m "1.0.1"
git push --tags
```

## 베타테스트 안내

- 화면 오른쪽 위 **의견 보내기**로 내용을 적고 복사해 전달해 주세요. 버전·화면 크기·브라우저 정보가 함께 담깁니다.
- 의견을 받을 구글폼 등이 있으면 `index.html`의 `FEEDBACK_URL` 상수에 주소를 넣으세요. 넣으면 양식 안에 폼 열기 버튼이 생깁니다.
- 테스트 중에는 **백업 파일**을 먼저 받아 두시길 권합니다. 버전이 올라가도 기록은 유지되지만, 사고는 언제든 납니다.
